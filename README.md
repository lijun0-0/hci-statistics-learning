# Supporting Understanding of Statistics in HCI

## Online access

Open the website in a browser: https://lijun0-0.github.io/hci-statistics-learning/
(Suggest using the Google Chrome on a laptop or desktop computer)

## How to use the learning website

1. Choose **Experiment Design** or **Statistics** on the start page (Suggest starting learning from experimental design).
2. Use **Next** and **Previous** to move through the learning pages.
3. Open **Chapters** in the top menu to jump directly to a unit.
4. The **gray next button** means that there are unfinished activities on this page.

## Run the source code locally

1. Download the project folder.
2. Open `index.html` in a desktop browser.
